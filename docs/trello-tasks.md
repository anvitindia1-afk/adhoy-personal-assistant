## 2. Як налаштувати дошку Trello

**Колонки (списки):**
1. `Backlog` — усі задачі
2. `To Do` — задачі поточного спринту
3. `In Progress` — у роботі (не більше 1–2 на людину)
4. `Code Review` — чекає рев'ю тімліда
5. `Done` — злито в `main` і перевірено

**Мітки (labels):**
- 🟦 `contacts` · 🟩 `notes` · 🟨 `core` · 🟪 `docs` · 🟥 `bug` · ⭐ `extra` (додаткові бали)

**Кожна картка містить:** опис, виконавця, файл, критерії готовності (чек-лист), залежності.

---

## 3. Спринти

| Спринт | Мета | Результат |
|---|---|---|
| **Sprint 0** (1–2 дні) | організація | ролі, дошка, репозиторій, структура файлів |
| **Sprint 1** | MVP контактів | контакти додаються, зберігаються, перевіряються |
| **Sprint 2** | нотатки + додаткове | нотатки з тегами, пошук, підказка команд |
| **Sprint 3** | якість і здача | тестування, README, презентація, фінальне рев'ю |

### Sprint 1 — Контакти (MVP)

**TASK-05. Базові поля: `Field`, `Name`, `Phone`**
- Виконавець: Developer 1
- Мітка: 🟦 contacts
- Файл: `contacts.py`
- Опис: базовий клас `Field` і спадкоємці. `Phone` приймає номер у форматах `0501234567`, `380…`, `+380…` (можна з `-` і дужками) і зберігає як `0XXXXXXXXX`.
- Готово, коли:
  - [ ] `Phone("123")` викликає `ValueError` із зрозумілим повідомленням
  - [ ] порожнє ім'я не приймається

**TASK-06. Поля `Email`, `Address`, `Birthday`**
- Виконавець: Developer 1
- Мітка: 🟦 contacts
- Файл: `contacts.py`
- Залежить від: TASK-05
- Опис: `Email` — формат `name@example.com`; `Address` — непорожній текст; `Birthday` — формат `DD.MM.YYYY`, не в майбутньому.
- Готово, коли:
  - [ ] `bob@mail` не приймається, `bob@mail.com` приймається
  - [ ] `31.02.1990` і майбутня дата не приймаються

**TASK-07. Клас `Record`**
- Виконавець: Developer 1
- Мітка: 🟦 contacts
- Файл: `contacts.py`
- Залежить від: TASK-05, TASK-06
- Опис: контакт складається з полів (композиція). Методи: `add_phone`, `edit_phone`, `remove_phone`, `find_phone`, `set_email`, `set_address`, `set_birthday`, `matches` (для пошуку), `__str__`.
- Готово, коли:
  - [ ] однаковий телефон двічі не додається
  - [ ] при неправильному новому номері старий не губиться

**TASK-08. Клас `AddressBook`**
- Виконавець: Developer 2
- Мітка: 🟦 contacts
- Файл: `contacts.py`
- Залежить від: TASK-07
- Опис: `add_record`, `find`, `delete`, `search` (за будь-яким полем, без урахування регістру).
- Готово, коли:
  - [ ] `search("kyiv")` знаходить контакт з адресою `Kyiv, ...`
  - [ ] видалення неіснуючого контакту дає зрозуміле повідомлення

**TASK-09. Дні народження через N днів**
- Виконавець: Developer 2
- Мітка: 🟦 contacts
- Файл: `contacts.py`
- Залежить від: TASK-08
- Опис: метод `get_upcoming_birthdays(days)` — контакти з днем народження від сьогодні до +N днів, відсортовані за датою.
- Готово, коли:
  - [ ] працює на межі року (грудень → січень)
  - [ ] 29 лютого в невисокосний рік не ламає програму

**TASK-10. Збереження даних**
- Виконавець: Developer 2
- Мітка: 🟨 core
- Файл: `storage.py`
- Опис: `pickle`-збереження контактів і нотаток у папку користувача `~/.personal_assistant/`.
- Готово, коли:
  - [ ] після перезапуску дані на місці
  - [ ] при першому запуску (файлів немає) програма стартує з порожньою книгою
  - [ ] пошкоджений файл не ламає програму

**TASK-11. Головний цикл, меню, декоратор помилок**
- Виконавець: Team Lead
- Мітка: 🟨 core
- Файли: `main.py`, `handlers.py`
- Опис: цикл «запит — відповідь», `parse_input`, меню при запуску та за командою `help`, `exit`/`close` зберігають дані, декоратор `input_error` (`ValueError`, `KeyError`, `IndexError`).
- Готово, коли:
  - [ ] будь-яке неправильне введення не закриває програму
  - [ ] Ctrl+C теж зберігає дані

**TASK-12. Команди для контактів**
- Виконавець: Developer 1 + Developer 2
- Мітка: 🟦 contacts
- Файл: `handlers.py`
- Залежить від: TASK-07, TASK-08, TASK-11
- Опис:
  - Developer 1: `add`, `change`, `remove-phone`, `phone`, `add-email`, `add-address`, `add-birthday`, `show-birthday`
  - Developer 2: `birthdays`, `search`, `delete`, `all`
- Готово, коли:
  - [ ] кожна команда повертає рядок (без `print` у функції)
  - [ ] кожна функція має декоратор `@input_error`

**TASK-17. ⭐ Підказка найближчої команди**

- Мітка: ⭐ extra, 🟨 core

## 5. Стендапи

Щодня 10–15 хвилин, кожен відповідає на 3 питання:
1. Що я зробив учора?
2. Що зроблю сьогодні?
3. Що мені заважає?

Скрам-майстер фіксує блокери й допомагає їх зняти.

## 6. Definition of Done (коли задача вважається готовою)

- [ ] код у гілці `feature/...`, відкрито Pull Request
- [ ] Team Lead зробив рев'ю й злив зміни в `main`
- [ ] програма запускається без помилок
- [ ] перевірено правильні та неправильні дані
- [ ] є коментарі до нового коду
- [ ] картка перенесена в `Done`
